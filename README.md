# champs-cod-benchmark

Code for **A Multimodal Benchmark for Evaluating Cause-of-Death Inference Using
Child Health and Mortality Data** (NeurIPS 2026 Evaluations and Datasets Track,
https://openreview.net/forum?id=8qRMs3zaOJ).

| Folder | Contents |
|--------|----------|
| [`LLM-analysis/`](LLM-analysis/) | LLM-based cause-of-death classification (gpt-oss-120b, gpt-oss-20b) and its evaluation |

Each folder has its own README with setup and reproduction steps.

The CHAMPS de-identified data are not included. Access is granted by the CHAMPS
network on application: https://champshealth.org/data/.
